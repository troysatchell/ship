What “verified” means

Every delivery is signed. The subscriber checks it in one call.

request headers
Ship-Signature: t=<unix seconds>,v1=<hmac-sha256 hex> Idempotency-Key: <same across retries and replays>
verifyWebhook(headers, rawBody, secret)
1 · parse t and v1 from the header
2 · reject if t is outside a 300 s window
3 · recompute HMAC-SHA256 over ${t}.${rawBody}
4 · timingSafeEqual against v1
✓ verified  signature + timestamp good ✗ rejected  one flipped byte

Same function the CI drill uses to assert tamper-rejection on every push. From @ship/sdk — 4.97 kB gzipped, zero runtime dependencies.

Header shape and steps from sdk/src/verifyWebhook.ts; the drill's tamper stage is scripts/drill/ttfe.ts.
